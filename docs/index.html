OPERA OPOTEK–vERAsonics Architecture for real-time multi-spectral photoacoustic imaging

An external microcontroller counts every laser pulse in hardware, so the wavelength label on each RF frame does not depend on host OS timing (validated so far on a phantom). Frames stream over 1 Gbps TCP to a separate workstation, where your own processing reads them from shared memory.

How it works

Three parts, each doing one job

01 · HARDWARE COUNT

MCU pulse tagging

An Arduino watches the laser's Flashlamp and Q-switch outputs on hardware interrupts and counts every pulse that actually fired. Verasonics asks it for the count after each frame, so the wavelength label does not depend on host OS timing.

02 · DECOUPLED STREAM

TCP + shared memory

The Verasonics host only acquires and sends. A separate MATLAB server averages frames per wavelength into a package (one averaged frame per wavelength) and writes it to a fixed-layout memory-mapped file. Any process that can map that file can read it; a MATLAB client is provided.

03 · YOUR PROCESSING

Pluggable client

The client drains packages and runs a placeholder you replace with your own beamforming, unmixing or monitoring code. In the poster, the client ran per-pixel spectral unmixing for ablation monitoring.

Get started

Run the offline demo in two MATLAB windows

No hardware is needed. Arduino is off by default, and the Verasonics template falls back to demo mode when no server is available.

  1. Clone the repository and run setup_paths from its root in MATLAB.
  2. Review the templates in config/.
  3. MATLAB #1: run server/run_tcp_server.m.
  4. MATLAB #2: run client/run_processing_client.m. It drains the queue and exits.
  5. With hardware: adapt verasonics/run_verasonics_host_template.m to your licensed SDK, flash arduino/trigger_monitor_minimal, and set cfg.hardware.enable_arduino = true.

Wiring. Laser Flashlamp Out → Verasonics trigger input and Arduino pin D2. Q-switch Out → Arduino pin D3. A pulse is counted when D3 rises within 1 ms of D2. Serial at 115,200 bps. The paper used an Arduino Mega.

git clone https://github.com/RyoMurakami-MedRobo/OPERA_Realtime-Multiwavelength-PA-Toolkit.git
cd OPERA_Realtime-Multiwavelength-PA-Toolkit
matlab -r "setup_paths; run server/run_tcp_server.m"
